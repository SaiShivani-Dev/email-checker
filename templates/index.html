EmailStatusReason
“Unknown” is an honest answer, not an error. Gmail, Yahoo, Outlook and many company mail systems accept every address at the SMTP stage (or never answer) so that nobody can harvest their user lists. Guessing would be wrong, so these are reported as unknown.
How to read the results
✓ likely to be delivered
Syntax is valid, the domain has a mail server, and that server accepted the address (or accepts every address, i.e. a catch-all).
✕ likely to bounce
Invalid syntax, a probable typo, a disposable domain, a domain with no mail server, or a server that explicitly says the mailbox does not exist.
? unknown
The address looks fine, but nobody could confirm the mailbox: the provider hides it, the server was unreachable or gave a temporary answer, or SMTP checks are not possible from this host.

Checks run in order and stop at the first decisive one: syntax → typo → disposable → DNS MX → provider rules → SMTP. The SMTP step only asks “would you accept this recipient?” and disconnects. It never sends a message.

Only the addresses you paste are checked, and they are not stored. Use this on addresses you are allowed to check.
